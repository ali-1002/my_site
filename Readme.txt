# 🌐 Personal Portfolio Website | 🌐 Shaxsiy Portfolio Veb-sayti | 🌐 Персональный сайт-портфолио

A modern and responsive personal portfolio website built to showcase my skills, projects, education, and contact information.
Mening ko'nikmalarim, loyihalarim, ta'limim va aloqa ma'lumotlarimni namoyish etish uchun yaratilgan zamonaviy va moslashuvchan shaxsiy portfolio veb-sayti.
Современный адаптивный сайт-портфолио, созданный для демонстрации моих навыков, проектов, образования и контактной информации.

---

## 🚀 About | 🚀 Loyiha haqida | 🚀 О проекте

This portfolio represents my journey as a **Junior Backend Developer**. It includes information about my technical skills, completed projects, education, certificates, and contact details.
Ushbu portfolio mening **Junior Backend Developer** sifatidagi faoliyatimni namoyish etadi. Unda texnik ko'nikmalarim, amalga oshirgan loyihalarim, ta'limim, sertifikatlarim va aloqa ma'lumotlarim joylashtirilgan.
Это портфолио отражает мой путь как **Junior Backend Developer**. Здесь представлены мои технические навыки, выполненные проекты, образование, сертификаты и контактная информация.

## 💻 Installation | 💻 O'rnatish | 💻 Установка

Clone the repository:
Repositoryni klon qiling:
Клонируйте репозиторий:

```bash
git clone https://github.com/ali-1002/portfolio.git
```

Open the project folder:
Loyiha papkasiga o'ting:
Перейдите в папку проекта:

```bash
cd portfolio
```

Open `index.html` in your browser.
`index.html` faylini brauzerda oching.
Откройте файл `index.html` в браузере.
